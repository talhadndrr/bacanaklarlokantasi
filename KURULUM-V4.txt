BACANAKLAR LOKANTASI V4 — KURULUM

Bu paket V3'teki SEO/footer değişikliklerini de içerir. V3 canlıya geçmediyse doğrudan V4 dosyalarını kullanabilirsin.

1) ZIP içindeki dosyaları bacanaklarlokantasi-git klasörüne kopyala.
2) Mevcut yemek/görsel dosyalarını SILME.
3) PowerShell:

cd "$HOME\OneDrive\Masaüstü\bacanaklarlokantasi-git"
git status
git add .
git commit -m "Bacanaklar V4 menu arama durum ve kullanilabilirlik"
git push origin main

- V3'te eksik kalan açık/kapalı JavaScript motoru tamamlandı.
- Durum Europe/Istanbul saatine göre hesaplanır.
- Ortak footer'ın eksik CSS'i tamamlandı.
